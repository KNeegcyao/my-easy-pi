## 推荐阅读方式

1. **按顺序阅读** — 从 01 到 10，每章末尾的练习建议动手做
2. **边读边跑** — 每篇文档都有"运行与验证"部分，打开终端跟着做
3. **遇到不懂的往回翻** — 每章 README 有前置知识说明
