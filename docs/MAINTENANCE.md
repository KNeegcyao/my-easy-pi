# 文档维护指南

## 新增章节

1. 创建 `docs/XX-章节名/` 目录（编号参考已有章节，允许使用 `02.5-` 等小数编号）
2. 创建 `README.md` 作为章节概览（说明本章目标、前置知识、章节结构）
3. 创建各小节文档，遵循文档模板格式
4. 更新 `docs/README.md` 的学习路线图表格
5. 更新 `docs/CHANGELOG.md`

## 更新已有文档

- **代码改了** → 更新对应文档的"代码实现"部分
- **新增功能** → 判断是否在现有章节加新小节，还是新建章节
- **删除功能** → 在文档中标记为"已废弃"或整体删除
- **API 变更** → 更新文档中的代码示例，并在 CHANGELOG 中记录

## 文档模板

每篇文档遵循以下格式：

```markdown
---
source: <源文件路径>
last_updated: YYYY-MM-DD
version: v0.1.0+
---

# 标题

## 1. 本节目标
- 学完本节你能理解什么
- 学完本节你能做什么

## 2. 前置知识
- 需要了解的前置概念

## 3. 核心概念
- 用通俗语言解释原理
- 配合类比/示意图

## 4. 代码实现
- 关键代码片段（带详细注释）
- 逐行解释

## 5. 运行与验证
- 如何运行/测试
- 预期输出

## 6. 小结
- 本节要点回顾
- 思考题
```

## 代码与文档的对应关系

每篇文档开头标注了对应的源文件路径，方便代码变更时定位：

```markdown
---
source: src/agent/loop.ts
last_updated: 2026-08-08
---
```

当需要更新文档时，搜索 `source:` 即可找到所有相关文档。

## 文档编号规则

- 章节目录：`01-`、`02-`、`02.5-`（允许插入）
- 章节内文件：`01-xxx.md`、`02-xxx.md`、`01.5-xxx.md`（允许插入）
- 特殊文件：`README.md`（章节概览）、`practice.md`（练习）

## 版本对应

- 文档顶部标注 `适用版本`，标明对应的代码版本
- 代码大版本更新时，需要审阅所有文档是否需要更新
