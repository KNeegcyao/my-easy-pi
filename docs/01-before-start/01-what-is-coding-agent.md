## 3. 核心概念

### 3.1 什么是 AI Coding Agent？

**通俗解释：AI Coding Agent 就是一个"会编程的助手"。**

想象你有一个**编程能力很强的实习生**：
- 你跟他说"帮我重构一下这个模块"，他会自己读代码、分析结构、写新代码、跑测试
- 你跟他说"这个 bug 看起来是内存泄漏"，他会自己去查日志、定位问题、修复代码
- 你跟他说"帮我写个脚本处理这些数据"，他会自己写代码、执行、验证结果

**关键区别**：你不是在给他下达"每一步"的指令，而是给他一个**目标**，他自己想办法完成。

### 3.2 与普通聊天机器人的区别

```
┌─────────────────────────────────────────────────────────────┐
│                    普通聊天机器人                             │
│                                                             │
│  用户: "帮我写一个读取 JSON 文件的函数"                      │
│  ────────────────────────────────────────────────────────    │
│  AI: "好的，以下是代码：\n```python\ndef read_json(path):\n │
│         import json\n        with open(path) as f:\n        │
│           return json.load(f)\n```"                         │
│                                                             │
│  → 你只能复制代码，自己粘贴到编辑器，自己运行                 │
│  → AI 只能"说"，不能"做"                                    │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│                    AI Coding Agent                           │
│                                                             │
│  用户: "帮我写一个读取 JSON 文件的函数"                      │
│  ────────────────────────────────────────────────────────    │
│  Agent: "好的，我来完成"                                    │
│    → 自动调用 read 工具查看当前目录结构                      │
│    → 自动调用 write 工具创建文件                             │
│    → 自动调用 bash 工具运行测试验证                          │
│    → 报告结果："已创建 utils/read_json.py，测试通过"         │
│                                                             │
│  → Agent 能自己操作文件系统、执行命令                        │
│  → AI 既能"说"又能"做"                                      │
└─────────────────────────────────────────────────────────────┘
```

**核心差异总结：**

| 维度 | 普通聊天机器人 | AI Coding Agent |
|------|--------------|----------------|
| **能力边界** | 只能生成文本回复 | 能读写文件、执行命令、编辑代码 |
| **交互方式** | 一问一答 | 目标驱动，自主规划执行 |
| **工具使用** | 无 | 可以调用多种工具（读文件、搜代码、跑测试） |
| **迭代能力** | 需要手动复制粘贴 | 自动修改代码、验证、再修改 |
| **上下文感知** | 对话历史 | 对话历史 + 文件系统 + 项目结构 + 执行结果 |

### 3.3 典型应用场景

#### 代码生成

```
用户: "创建一个 Express.js 的 REST API 路由，包含 CRUD 操作"
Agent:
  1. 查看项目现有结构
  2. 创建路由文件
  3. 创建数据模型文件
  4. 创建路由注册入口
  5. 运行测试确认没有语法错误
```

#### 代码重构

```
用户: "把这个模块从 Class 写法改成函数式写法"
Agent:
  1. 读取模块所有文件
  2. 分析依赖关系
  3. 逐步重构每个函数
  4. 运行测试确保功能不变
```

#### Bug 调试

```
用户: "生产环境出现 500 错误，帮我查一下"
Agent:
  1. 查看错误日志
  2. 定位到报错代码行
  3. 分析可能的原因
  4. 修复代码
  5. 运行单元测试验证
```

#### 项目管理

```
用户: "帮我整理一下项目依赖，看看有哪些可以升级"
Agent:
  1. 读取 package.json
  2. 检查每个依赖的最新版本
  3. 分析兼容性
  4. 生成升级报告
  5. 可选：自动升级并测试
```

### 3.4 主流项目介绍

#### Claude Code（Anthropic）

Claude Code 是 Anthropic 推出的 AI 编程助手，运行在终端中。它能够：
- 理解整个代码库
- 执行复杂的多步骤编程任务
- 直接在终端中运行命令和编辑文件
- 支持 Git 操作（创建分支、提交代码、创建 PR）

> 这是目前最成熟的 AI Coding Agent 之一，也是 piagent 的重要参考。

#### Cursor

Cursor 是一个 AI-first 的代码编辑器，基于 VS Code 深度改造。它的特点：
- 在编辑器内直接与 AI 对话
- 支持内联代码编辑（Tab 接受建议）
- 能理解整个项目的上下文
- 集成了 Claude 和 GPT 模型

> Cursor 和 Claude Code 的区别：Cursor 是"编辑器 + AI"，Claude Code 是"终端里的 AI 助手"。

#### 原版 pi（earendil-works/pi）

pi 是一个开源项目，地址是 [github.com/earendil-works/pi](https://github.com/earendil-works/pi)。它是 piagent 的直接灵感来源，采用了类似的分层架构设计。

> piagent 参考了 pi 的设计哲学与代码结构，但做了大量简化和调整，使其更适合学习。

### 3.5 本项目的定位

**piagent 是一个"学习用精简版"AI Coding Agent。**

```
┌─ 完整产品（Claude Code） ─────────────────────────────────┐
│  • 数十万行代码                                            │
│  • 多团队协作开发                                          │
│  • 生产级可靠性                                            │
│  • 复杂的权限和部署系统                                    │
└───────────────────────────────────────────────────────────┘

┌─ 学习项目（piagent） ───────────────────────────────────┐
│  • ~3000 行 TypeScript 代码                               │
│  • 单人可读完的代码量                                     │
│  • 完整但精简的 6 层架构                                  │
│  • 每一行代码都为教学服务                                  │
└───────────────────────────────────────────────────────────┘
```

**piagent 适合这样的你：**
- 想深入理解 AI Coding Agent 的工作原理
- 想从零搭建一个可用的 Agent 系统
- 想学习 TypeScript 分层架构设计
- 想为将来贡献开源项目或开发自己的 Agent 打基础

**piagent 不适合：**
- 需要一个生产级的 AI 编程助手（请用 Claude Code 或 Cursor）
- 不想了解底层原理，只想"开箱即用"

## 6. 小结

### 本节要点

- AI Coding Agent 是一个**能自主使用工具**的 AI 编程助手，类比"会编程的实习生"
- 与普通聊天机器人最大的区别是：Agent 能**操作文件系统**、**执行命令**、**迭代修改代码**
- 典型应用场景：代码生成、重构、调试、项目管理
- 主流项目：Claude Code（终端助手）、Cursor（AI 编辑器）、原版 pi（开源参考）
- piagent 定位为**学习用精简版**，代码量适中，适合深入学习

### 思考题

1. 如果要求 AI Coding Agent **不能**调用任何工具（不能读文件、不能执行命令），它还能完成编程任务吗？能完成到什么程度？

2. 有人说"AI Coding Agent 是编程的终极形态"，你觉得这句话对吗？为什么？

3. 假设你是一个公司的 CTO，你会放心让 AI Coding Agent 直接修改生产环境的代码吗？如果不放心，你会在哪些环节加控制？

4. 对比 Claude Code 和 Cursor 两种形态：一个在终端里，一个在编辑器里。你觉得哪种更自然？为什么？
