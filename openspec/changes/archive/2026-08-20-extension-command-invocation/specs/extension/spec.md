## Purpose

定义扩展自定义命令的完整契约:扩展通过注册与查询 API 声明命令,交互式会话消费这些命令并在命中时执行其行为,使扩展注册的命令真正可被用户调用。

## ADDED Requirements

### Requirement: 命令注册与枚举
系统 SHALL 允许扩展按名称注册自定义命令,并可枚举当前所有已注册命令名。

#### Scenario: 注册扩展命令
- **WHEN** 扩展调用注册 API 注册一个命令
- **THEN** 该命令名被记录,可在后续被枚举与查询

#### Scenario: 枚举全部命令
- **WHEN** 调用方枚举已注册命令
- **THEN** 返回当前所有命令名的列表,含扩展新增的条目

### Requirement: 命令调用入口
当用户的交互输入命中一个已注册扩展命令时,系统 SHALL 执行该命令携带的参数并返回其结果。

#### Scenario: 斜杠前缀触发
- **WHEN** 用户输入以 `/` 开头,首词命中一个已注册扩展命令名
- **THEN** 系统调用该命令,把首个词之后的参数交给它的 execute,并把结果呈现给用户

#### Scenario: 首词精确触发
- **WHEN** 用户输入不以 `/` 开头,但首词精确命中一个已注册扩展命令名
- **THEN** 系统调用该命令并把参数交给它的 execute,结果呈现给用户,而非把它当作普通对话消息

#### Scenario: 无参调用
- **WHEN** 用户输入一个命中的扩展命令名但不带参数
- **THEN** 系统以空参数列表调用该命令,并正常返回其行为

#### Scenario: 未命中不入错误
- **WHEN** 用户输入既不匹配内置命令也不匹配任何已注册扩展命令
- **THEN** 系统按既有的未知输入处理路径执行,不把普通输入误当作扩展命令
