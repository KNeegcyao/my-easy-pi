## ADDED Requirements

### Requirement: 补全展示槽可折叠
系统 SHALL 在补全/树无内容时把展示槽折叠为 0 行，不占用布局高度；有内容时按实际内容撑开（上限最大高度）。

#### Scenario: 无内容时折叠
- **WHEN** 补全展示槽没有挂载任何内容
- **THEN** 该槽渲染返回 0 行，底部布局不为其预留空间

#### Scenario: 有内容时按需撑开
- **WHEN** 补全展示槽挂载了选择器且其渲染行数小于等于最大高度
- **THEN** 该槽渲染返回与内容等高的行数，输入框被相应上推

#### Scenario: 超出最大高度截断
- **WHEN** 挂载内容渲染行数超过最大高度
- **THEN** 该槽截断至最大高度，不无限增长

#### Scenario: 关闭后立即折叠
- **WHEN** 内容被移除（关闭补全/树导航）
- **THEN** 该槽立即回到 0 行，输入框恢复原位
